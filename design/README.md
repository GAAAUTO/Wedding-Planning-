# Original floral installation

`original-floral-installation.glb` is an editable export of the original procedural wedding scene, including the flowers, support structure, fabric, jewellery and candle geometry. It is provided for inspection and further 3D art work in Blender or another glTF-compatible editor.

The website's animated version is generated by `src/CinematicScene.js`. The GLB is an authoring asset, not a scanned or photographed floral installation. This export captures one pose; motion is defined in the JavaScript source.

No meshes or textures from the user's reference screenshots or from the public repositories inspected during research were included.
